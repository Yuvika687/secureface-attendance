Collection mode (domain adaptation data)

When on, the face crop of each recorded frame (at most one per second) is saved with its label and scores to data/domain_adaptation/ (not in git). See docs/domain_adaptation_plan.md. Only collect from people who agreed to it.

Choose a category, then press Start recording.
—
Results

One row per camera frame with exactly one face, using the scanner's own decision (average of the last 5 frames, same thresholds). Real person: correct = LIVE, wrong = SPOOF. Attack: correct = SPOOF, wrong = LIVE. UNCERTAIN means "retry" and is counted separately. APCER = attack frames judged LIVE. BPCER = real-person frames judged SPOOF. HTER for an attack category = (its APCER + overall BPCER) / 2. Frames with no face or several faces are recorded but not counted.
